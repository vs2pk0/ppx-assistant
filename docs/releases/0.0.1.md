# 皮皮虾助手 0.0.1

## 本次更新

- 版本命名从日期版本切换为 0.0.x，本版为 0.0.1。内部版本号继续递增，可覆盖安装之前的 r6。
- 支持皮皮虾 6.5.0，保留 6.2.0 适配；首页和关于页统一显示适配列表及当前安装版本。
- 新增 GitHub Actions 自动构建、测试、签名和 Release 发布，提供 APK 与 SHA-256 校验文件。
- Actions 构建摘要和 Release 页面展示每个版本的中文更新说明。

## 功能与验证

继承此前版本的去广告、去水印保存、图片保存按钮、评论快捷设置及颜色、楼中楼视频入口、消息 99+ 等功能。本次没有修改这些 Hook 的实现。

6.5.0 回归中，50 项真实宿主模型检查、17 项单元测试通过，真机验证了视频、音频、图片保存、红色评论、消息角标、倍速和正式冷启动。完整范围见[验证报告](https://github.com/vs2pk0/ppx-assistant/blob/v0.0.1/docs/functional-test-6.5.0.md)。

自动操作仍隐藏并停用。GIF 保存、楼中楼视频实际上传播放、长按倍速及部分服务端场景未在 6.5.0 全部重新实测。红色评论在其他客户端的显示取决于其支持情况。

## 安装

下载下方 APK 覆盖安装，在 LSPosed 中确认作用域包含皮皮虾，然后彻底退出并重新打开皮皮虾。仅列出已验证的宿主版本 6.5.0、6.2.0。
