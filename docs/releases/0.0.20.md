# 皮友助手 0.0.20

## 本次更新

- 适配皮皮虾 6.6.5，恢复评论区送神功能。
- 新增「隐藏首页搜索入口」。修复「去除头像列表」，收起头像栏后帖子会直接顶上来。
- 「自动送神评」在首批评论和帖子已展示的评论中查找神评，发现至少 2 条不同的神评时会跳过。

## 首页功能回归验证

- 「隐藏金币悬浮球」可隐藏推荐页 ×2 阅读红包。「隐藏底栏福利入口」可单独隐藏底栏福利按钮。
- 「管理频道」可将旧的「图片」「文字」选择带到「图文」频道。开启「去除底栏」后，横滑切换到视频时底栏保持隐藏。

## 安装说明

正式签名包可覆盖安装 0.0.17 正式版。修改相关设置后，强行停止并重新打开皮皮虾。使用现代框架时需支持 libxposed API 102。
