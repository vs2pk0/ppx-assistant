# 皮友助手 0.0.12

## 本次更新

- 现代 LSPosed 入口与 Service 升级到 libxposed API 102，保留独立的旧版 Xposed 入口。模块设置可查看配置同步状态和运行日志。
- 新增自动送神评，默认关闭。开启后可选择第一楼、首批顶层评论中点赞最多的评论，或按显示顺序指定楼层。每次启动皮皮虾后，同一帖子最多尝试一次。
- 评论工具栏新增自定义视频入口，支持保存去水印视频、查看下载进度、分组和预览。自定义表情支持批量导入收藏、清空分组、跨组移动，调整了弹窗高度和预览行为。
- 新增完整 ZIP 备份，包含模块设置、表情和视频分组、媒体原文件及封面。支持导入旧版 JSON，并在恢复时校验媒体和复用重复文件。
- 按用途重排模块设置。「我的」页新增可开关的皮友助手入口，优化头像返回时闪烁和评论回复栏显示。

## 安装与验证

包名 `io.github.vs2pk0.piyou`，内部版本号 `20261111`。使用现代 LSPosed 时，框架须支持 API 102。覆盖安装后重启皮皮虾即可。

在皮皮虾 6.6.1 真机上验证了三种选楼方式、同帖去重、回复栏和媒体弹窗。自动送神评的实际投票结果尚未实测。自动送神评适配 6.5.5 和 6.6.1。
