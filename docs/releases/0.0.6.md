# 皮友助手 0.0.6

## 本次更新

- 修复部分评论动图保存为 WebP 后，在相册里无法播放的问题：动画 WebP 现在逐帧转换为 GIF 后保存。
- 保留动画帧、帧叠加和清除效果，并按帧时长导出；普通 GIF 继续原样保存，静态图片保持原格式。
- 优化长动图转换耗时，使用固定 256 色量化；转换失败时不向相册写入不完整文件。

## 使用说明

安装后彻底退出并重启皮皮虾，重新打开动图点击保存。已经保存的 WebP 不会自动转换。GIF 文件通常更大，颜色有少量损失，透明区域使用白底。

适配皮皮虾 6.2.0、6.5.0。包名 io.github.vs2pk0.piyou，内部版本号 20260923，可覆盖安装旧版模块；本次不是 LSPatch 集成包。

## 验证

手机实际 WebP 样本转换后，输入输出均为 277 帧、284×360、27.7 秒，Android 确认为动画 GIF；文件从约 2.6 MB 增至 7.0 MB。已通过单元测试、Lint 与正式构建。此轮验证转换器，不代表重新完成全部宿主功能回归。
