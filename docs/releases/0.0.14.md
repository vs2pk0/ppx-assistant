# 皮友助手 0.0.14

## 本次更新

- 新增「关闭新徽章弹窗」开关，可在「启动与隐私 → 启动与提示」找到。
- 新增「隐藏帖子和评论的昵称徽章」开关，覆盖首页列表里的「潜力皮友」等创作徽章，以及帖子详情和评论里的昵称徽章。可在「我的与个人资料 → 用户信息」找到。
- 重做「关于与支持」，将赞赏区放到顶部，保留微信和支付宝赞赏码，新增爱发电和更多软件入口。
- 精简 README，集中展示主要功能、真机截图和支持方式。

## 安装说明

两个徽章开关默认关闭。切换后，强行停止并重新打开皮皮虾。正式包可覆盖安装 0.0.13，使用现代框架时需支持 libxposed API 102。
