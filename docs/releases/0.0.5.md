# 皮友助手 0.0.5

## 本次更新

- 新增启动自动检查更新，以及“关于与支持”中的手动检查更新。有新版本时显示 GitHub Release 更新说明，可选择“暂不更新”或“前往更新”；手动检查无新版本时提示“暂无更新”。
- 更新弹窗支持 Markdown 标题、列表、加粗与链接，长内容可滚动查看，适配深浅主题。自动检查网络失败时不弹出提示，手动检查失败时可稍后重试。
- 分享面板新增原生样式的“转发”入口，置于功能栏第一项，支持将当前内容的文字、图片或视频带入发帖页；楼中楼文字回复可长按后选择分享。进入编辑页后由用户决定是否发布。
- 补充视频备用地址，修复部分视频转发时遗漏视频的问题；媒体下载失败时提示错误，避免生成缺少媒体的帖子。
- 修复详情分享中“复制文字”可能闪退的问题。
- 调整动图保存：优先尝试原始下载地址，验证动画后再保存，避免把静态预览当成完整 GIF；无法取得完整动图时明确提示失败。

## 使用说明

安装后重启皮皮虾，使模块改动生效。检查更新位于助手自身的“关于与支持”，更新按钮打开对应 GitHub Release 下载页，不会自动下载安装。

版本号为 0.0.5，包名保持 io.github.vs2pk0.piyou，可覆盖安装旧版助手。本次发布的是模块 APK，不是 LSPatch 宿主集成包。

## 验证范围与限制

- 现有适配版本为皮皮虾 6.2.0、6.5.0；本轮转发真机验证使用 Android 16 / 皮皮虾 6.5.0，详见[转发测试记录](https://github.com/vs2pk0/ppx-assistant/blob/v0.0.5/docs/forward-test-6.5.0.md)。6.2.0 未重新进行真机回归。
- 使用显示版本 0.0.2 的测试包，对线上 0.0.4 验证了启动更新弹窗、取消、手动检查以及 Markdown 渲染。
- 动图修复尚未复测用户原先失败的具体样本；Android 8 无法验证完整动画时会提示失败。未验证服务端最终发布、楼中楼视频样本及无 root 环境的完整功能。
