# 皮友助手 0.0.3

## 本次更新

- 应用包名迁移为 `io.github.vs2pk0.piyou`，与 LSPosed 官方收录仓库一致。
- 同步更新传统和现代框架的作用域、设备测试入口；配置 Provider 与评论设置跳转使用新应用包名。
- 版本号为 0.0.3，内部版本号为 20260920，应用名称仍为“皮友助手”。
- 增加 LSPosed 收录仓库下载入口，提供中文更新说明及 APK 的 SHA-256 校验文件。

## 兼容与验证范围

适配皮皮虾 6.2.0、6.5.0。本次仅调整发布包名及相关配置，不新增 Hook；自动操作继续隐藏停用。此前的宿主验证范围见 [6.5.0 测试记录](https://github.com/vs2pk0/ppx-assistant/blob/v0.0.3/docs/functional-test-6.5.0.md)。包名迁移不代表已重新完成全部宿主功能实测。

## 安装说明

本版会作为新应用安装，不能覆盖 `com.vs2pk0.piyou` 或 `com.akari.ppx`，旧设置不会自动迁移。请在 LSPosed 中停用旧模块，启用包名为 `io.github.vs2pk0.piyou` 的皮友助手，勾选皮皮虾作用域，重新配置需要的功能，再彻底退出并重启皮皮虾。
