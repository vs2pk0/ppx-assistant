# 皮友助手 0.0.2

## 本次更新

- 应用名称改为“皮友助手”，桌面、设置首页、关于页、模块加载提示及安装包名称同步更新。
- 应用包名改为 `com.vs2pk0.piyou`，同步适配配置 Provider、评论快捷设置跳转和 LSPosed 作用域。
- 版本使用 `0.0.x` 系列，本版为 0.0.2。0.0.1 的构建因本次更名取消，未发布安装包。
- 新增 GitHub Actions 自动测试、lint、签名构建和 Release 发布，构建摘要及发布页面显示中文更新说明，提供 APK 和 SHA-256 校验值。
- 首页和关于页显示支持皮皮虾 6.5.0、6.2.0。

## 功能与验证范围

继承去广告、去水印保存、图片保存按钮、评论快捷设置及颜色、楼中楼视频入口、消息 99+ 等功能。此前 6.5.0 回归包含 50 项真实宿主模型检查、17 项单元测试，实测视频、音频、图片保存、红色评论、消息角标、倍速和正式冷启动，见[完整记录](https://github.com/vs2pk0/ppx-assistant/blob/v0.0.2/docs/functional-test-6.5.0.md)。该记录使用更名前的包名，本次更名不能视为重新完成全部宿主实测。

自动操作继续隐藏停用。GIF 保存、楼中楼视频实际上传播放、长按倍速及部分服务端场景未在 6.5.0 全部重新实测。

## 安装说明

本版更换了包名，会作为新应用安装，不能直接覆盖旧版“皮皮虾助手”，旧设置不会自动迁移。请在 LSPosed 中停用旧模块，启用“皮友助手”并勾选皮皮虾作用域，重新设置需要的功能后彻底退出并重启皮皮虾，避免两个模块同时作用。
