# 皮友助手 0.0.13

## 本次更新

- 「评论与发布 → 评论功能」新增「显示送神按钮」。开启后，一级评论和评论详情底栏会在点赞旁显示带星标图标的送神按钮。
- 「帖子与内容过滤 → 帖子操作栏」新增「列表常驻插眼按钮」。开启后，在支持插眼的首页帖子右侧显示插眼入口。
- 自动送神评会等评论区可见后再执行，并提示送神结果或未送出的原因。保留首楼、首批评论中点赞最多、指定楼层三种目标，同一次运行中每帖最多尝试一次。
- 新增的两个显示开关默认关闭。修改后重启皮皮虾生效。

## 安装与验证

包名 `io.github.vs2pk0.piyou`，内部版本号 `20261112`。正式版可覆盖安装 0.0.12。使用现代 LSPosed 时，框架须支持 API 102。

送神与插眼入口适配皮皮虾 6.5.5 和 6.6.1，已在 6.6.1 真机上验证显示和开关。
