# 皮友助手 0.0.4

## 本次更新

- 新增“跳过启动展示页”，同时处理应用内开屏和 Android 12 及以上的系统启动主题，隐藏卡通启动图，保留首页初始化流程。
- 修复仅隐藏应用内开屏时，系统启动窗口仍显示卡通图的问题；关闭开关并进入一次皮皮虾后可恢复原启动主题。
- 新增“母虾提示颜色”选择器，默认保留原粉色，支持预设颜色、RGB 滑块、十六进制颜色输入、预览和恢复默认。
- 补充启动图与昵称颜色的调试探针、颜色校验测试及真机验证记录，调试探针不包含在正式安装包中。

## 使用说明

“跳过启动展示页”位于“广告与内容过滤”，默认关闭。开关变更后先进入一次皮皮虾，下一次冷启动生效；初始化时仍可能短暂白屏，不会缩短网络加载时间。Android 12 以下仅处理应用内开屏。透明启动主题在当前手机上会恢复原卡通图，因此未采用。

系统启动主题会持久化。停用或卸载模块前，如需恢复原启动图，请先关闭开关并打开一次皮皮虾。

“母虾提示颜色”位于“浏览与播放”，修改后重启皮皮虾生效。选择颜色不会自动开启母虾提示。

## 兼容与验证范围

现有适配版本为皮皮虾 6.2.0、6.5.0。本次真机验证使用 Android 16 / 皮皮虾 6.5.0，确认开屏开关的录屏对比、正式包冷启动，以及粉色和自定义蓝色昵称渲染。6.2.0 仅静态核对开屏方法，未重新进行真机验证。颜色对话框尚未完成全部触控、横屏和大字体回归。
