# “我的”页切换闪烁修复记录

## 原因与处理

`MyPageEntryHider` 原来在 `OnGlobalLayoutListener` 中把整行设为 `GONE`。此时本轮布局已完成，画面可能先显示隐藏后留下的空白，下一次布局才收缩，造成卡片与助手入口短暂跳位。

改为布局回调只标记待检查，在 `OnPreDrawListener` 中沿用原有定位与隐藏逻辑。如果本轮改变了可见性，则取消本帧绘制，等待收缩后的布局再显示。已隐藏的容器不重复设置，无布局变化时也不重复遍历页面。
