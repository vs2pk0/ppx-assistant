# 自定义表情批量导入与弹窗验证

日期：2026-10-27。设备：小米 13 Ultra（9d9975c1），Android 16；皮皮虾 6.5.5，LSPosed IT API 102。

## 功能

- 自定义表情弹窗增高到屏幕可用高度的 82%，分组和管理按钮固定在上方，表情列表独立滚动。
- 增加“导入全部收藏”，读取宿主当前收藏列表，导入到“收藏表情”分组；后台复制本地缓存，显示数量、百分比和横向进度条，最后一次性合并保存。
- 同一分组按 URI 去重；已有远程记录可补全本地缓存。保存失败时不会将本次批量结果替换进内存缓存。
- 增加“全部删除表情”，确认提示展示所有自定义分组的表情总数。确认后清空分组内容、保留分组名称，不调用宿主删除收藏接口。缓存图片保留，便于再次导入。
- 列表使用原生 GridView 复用单元格；图片按显示尺寸解码，离屏动图停止，避免全部导入后同时解码和播放所有图片。

## 真机验证

1. 安装前备份模块 APK、配置、自定义分组文件及收藏数据库快照；原有分组“美女”有 8 张表情。
2. 覆盖安装正式构建，重启皮皮虾，确认加高的弹窗与两个新增按钮正常显示。
3. 首次导入：宿主收藏服务返回 46 张，新增 46 张，无法读取 0 张；落盘文件包含原分组 8 张及“收藏表情”46 张，46 个 URI 唯一，全部保存了本地缓存。
4. 录屏确认进度从 4/46（8%）、22/46（47%）、43/46（93%）持续更新到完成。
5. 再次导入：新增 0 张、已有 46 张；落盘数据与首次导入后完全一致。
6. 点击“全部删除表情”，确认提示显示 54 张、保留分组名称及不影响官方收藏。点击取消后验证数据完全一致；未实际清空用户表情。
7. 连续滚动可到达第 46 张表情；重启宿主后落盘数据仍完全一致，原有分组内容未变。
8. 49 项单元测试、Release 构建（含 lintVital）、`git diff --check` 通过；主进程及推送进程均为 `installed=56 failed=0`。

宿主收藏数据库快照有 278 条历史记录，其中只有 46 条的本地图片仍存在。宿主初始化会过滤缺失文件；导入使用其当前公开的收藏列表，不恢复宿主不可用的历史记录。
