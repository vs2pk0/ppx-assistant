# 自定义视频与评论工具栏验证

日期：2026-10-27。设备：小米 13 Ultra，Android 16，皮皮虾 6.5.5，LSPosed API 102。

## 功能

- 评论工具栏的助手设置、自定义表情改用与原生按钮接近的灰色线框图标；自定义视频紧邻表情右侧。
- 模块的「表情与视频 → 自定义视频分组」控制视频入口及分享菜单的「存视频」。新开关默认关闭，本次已在测试手机打开。
- 分享菜单的「存视频」选择或新建分组后，解析当前内容的原始播放流并下载。不会在解析失败时退回带水印下载地址。
- 保存过程立即显示 loading，下载时显示百分比和下载大小，支持取消。网络中断最多尝试三次，服务端支持 Range 时续传，不支持时重新下载。校验文件长度、视频尺寸、时长及封面后才写入分组。
- 视频库支持预览、加入未发布的评论、分组创建及重命名、跨分组移动和移出。移动会去重，同时保留空的源分组。
- 图标布局和图片/视频底部弹窗使用公共组件。分组 JSON 使用固定字段及原子写入，避免混淆后字段变化或中途写入损坏。
