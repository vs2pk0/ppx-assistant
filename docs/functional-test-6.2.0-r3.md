# 皮皮虾 6.2.0：r3 快捷操作与维护信息

版本：26.09.12-r3。测试环境：Android 16、SukiSU Ultra、LSPosed modern API 102。

## 变更

- 关于页维护者为 lilei / vs2pk0，提供 GitHub 主页、源码、Issues、Releases 入口；保留原作者与 GPL-3.0 署名。
- 评论工具栏追加“虾”按钮，打开助手的轻量设置弹窗，修改颜色、敏感词处理和楼中楼视频开关。
- 颜色在发布时读取，普通文本立即生效；已有 @、时间标记不重复包装。视频入口开关重新打开评论框后生效。
- 快捷设置和助手主设置共用 DataStore，并同步 LSPosed 远程配置。显式 Activity 入口兼容宿主无法发现模块 ContentProvider 的情况。
- 图片查看页追加“存”按钮，每次取当前页的图片，复制原始内容至 `Pictures/皮皮虾`，按 GIF/WebP/PNG/JPEG 真实文件头写入相册类型。
- 图片保存后台执行，保存期间禁用重复点击；失败清理未完成相册条目。原生下载入口仍使用原有 Hook。
- 移除旧维护者的捐赠、群组、更新服务代码和本机开发者认证标记。

## 验证

- 12 项 JVM 单元测试通过。
