# 皮皮虾 6.2.0 · 26.09.12-r2 适配记录

本次在原有 6.2.0 适配基础上增加功能，原有逐项验证范围见 [上一轮报告](functional-test-6.2.0.md)。设备为已授权的 SukiSU Ultra / LSPosed 手机，宿主版本 6.2.0 (620)。

## 功能与行为

| 项目 | 结果与范围 |
| --- | --- |
| 去水印保存文案 | 分享面板的保存视频/图片动作按对应功能是否实际安装改名；播完视频后的保存入口同步改名。保留原有监听器和下载流程。 |
| 评论蓝色 | 已在自己的旧帖发布，重进后依然蓝色，表情正常。 |
| 评论红色 | 旧助手 type=3 在 6.2.0 已显示成黑色。改为显式颜色标记；服务器保存了标记，本模块补上评论区渲染。真机确认颜色 #D93025。对方客户端是否显示取决于其兼容性。 |
| 不处理 | 不改写新评论；不会更改已发评论。含既有富文本/@或时间链接的内容保留原格式，避免嵌套标记破坏内容。 |
| 楼中楼视频 | 已确认回复入口、视频选择器、2秒纯色测试视频选择、发送、楼中楼显示和点开播放。 |
| 消息99+ | 修正去除红点覆盖消息角标的冲突；99+独立于个人资料自定义开关，且仅影响本机显示。两个开关同时开启的首页已显示99+。 |
| 启动提示 | 每次宿主进程冷启动，在主界面首次获得焦点后显示实际初始化结果；普通前后台切换不重复。失败时显示失败项数。 |
| 加载稳定性 | 空扫描不再标记已完成，应用 attach 回调错过时允许主界面回调重新初始化与扫描；配置同步直接读 DataStore，避免使用异步缓存旧快照。 |
| 设置布局 | 保留原配置键，分区卡片、全局搜索、五个页签、深浅主题、系统栏对比度；多行说明自动撑开卡片。 |
| 图标 | 使用内置 imagegen 参考宿主当前图标生成新的助手小虾，源图与完整提示词见 [图标设计记录](design/icon-design.md)。 |

启动提示只证明当前进程已执行模块代码。若框架完全没有注入，模块无法凭空显示提示；框架启用状态与宿主本次加载结果在设置中分别说明。

## 实现原则

颜色转换集中在纯函数中；下载标签和实际下载逻辑分离，并以功能初始化成功为条件。复用原偏好组件和存储键，避免配置迁移。移除旧启动弹窗中的自动关注作者和退出进程逻辑。未复制其他助手的完整实现，仅对照功能及宿主协议进行适配。
