# 26.09.13-r5 自动操作排查

目标为手机当前皮皮虾 6.2.0 (620)。本次采用用户允许的降级方案：自动操作整组隐藏并停用，不宣称恢复了自动化功能。

## 代码与宿主核对

| 功能 | 检查结果 | 处理 |
| --- | --- | --- |
| 自动切换 / 播完切换 | 6.2.0 仍有 DetailPagerFragment、SwipeControlledViewPager 与视频 k_(int) 回调；但旧实现仅覆盖详情页，未处理首页、初次进入、页面销毁和任务去重。传给 postDelayed 的延迟为 Int，当前反射匹配要求 Long，不能解析对应方法。 | 停用 BrowseHook、CommonHook。 |
| 自动点赞 / 点踩 | 依赖同一个详情页翻页入口；暂停标记在下一次回调被重置，未取消已排队的切换；没有去重及已赞/踩判断。 | 停用 CommonHook 和相关开关。 |
| 自动评论 | 点赞条件分支没有检查 auto_comment 总开关，旧评论内容可能在关闭功能后继续提交；默认条件读取也与界面默认值不同。 | 整个执行入口停用，历史开关读取强制为 false。 |
| 评论自动点赞 | 在 setRealCommentId 时提交点赞，未过滤无效 ID / 重复回调，临时评论计数被直接写成 1，并不代表服务端成功。 | 停用 CommentDiggHook。 |
| 自动插眼 | 评论触发条件把发布模型 fakeId 改成固定 666，且 wardCell 固定使用类型 1；缺少成功确认及去重。 | 停用 WardHook。 |
| 自动送神 | 状态 getter 内发起点赞、送神请求，并把 aliasItemId 当成本地状态标记。没有证明服务端接受请求。 | 禁止自动开关；SendGodHook 仅转换显示状态，不再发送请求或修改模型 ID。 |
| 转发计数 | shareCell 只是重复调用 100 次，没有服务端成功判断；不能保证 +100。 | 停用自动 ShareHook，保留精简分享的独立 Hook。 |

## 实现范围

- 共 16 个自动操作设置（含条件、频率、时间及暂停选项）从分类和全局搜索移除。
- 使用统一可用性规则控制界面与执行入口；保留历史配置数据，不清空用户偏好。
- 跳过 5 个自动 Hook 的安装，不计为初始化失败；即使旧开关为 true，也不会执行。
- 手动送神入口保留，服务端结果不作保证；解除已送满限制不再附带自动点赞。
- 本轮不做批量点赞、点踩、转发、评论等线上请求测试。

## 验证结果

- 17 项 JVM 回归测试通过：覆盖分类完整性、自动项与子选项全部不可见、5 个执行入口被禁用、旧开关即使默认 true 也返回 false，以及原有下载源/过滤/评论颜色测试。
- assembleRelease、lintRelease、git diff --check 通过；lint 仍有原有警告。
- 正式签名 APK 已覆盖安装，手机版本为 26.09.13-r5 (20260916)。
- 真机首页显示五个功能分类及关于入口，自动操作不再出现；截图 /tmp/ppx-r5-home.png。全局搜索共用同一分类数据源，隐藏项由回归测试验证。
- 正式宿主冷启动日志明确跳过全部 5 个自动 Hook；显示“加载成功”，40 项初始化成功，无 init failed / Exception / Error。日志位于本地 build/device/r5-release.log。
- 本轮确认其余 Hook 初始化正常，未重做历史版本所有功能的端到端测试。
