# 转发功能验证记录

日期：2026-09-13。宿主：皮皮虾 6.5.0；设备：Android 16 / SukiSU Ultra / LSPosed 2.0。

## 行为

- 列表、帖子详情、评论详情分享面板增加“转发到发帖页”。
- 楼中楼文字回复长按菜单补充“分享”，进入专用转发菜单。
- 优先读取当前回复，其次当前评论或帖子；保留文字和图片顺序，不混入父帖媒体。
- 图片和视频先完整下载，再使用宿主媒体模型打开原生编辑页；由用户继续编辑、选择是否发布。
- 下载失败或缺少媒体地址时整体失败，显示提示；取消后不打开编辑页。
- 转发页跳过既有草稿加载，丢弃转发内容时不清除旧草稿。选择原生“保存”仍按宿主逻辑保存本次编辑。
- 成功下载的媒体保留在宿主私有 files/piyou-forward 中，以供原生草稿后续读取；失败下载会清理本次临时目录。
- 在分享面板直接处理“复制文字”，避免进入宿主未初始化 currentFeedItem 的 ACTION_PI 回调。
